[V] O cache Ollama exigiu preservar seus links relativos de manifestos para blobs internos. Links externos, caminhos de escape e snapshots sem cobertura de todos os volumes são recusados. A compactação usa gzip em fluxo compatível com Python 3.11, com leitura e escrita em blocos. Doze testes de segurança/compatibilidade passaram no host e em Python 3.11.18 no container; um ensaio Linux adicional confirmou UID/GID, diretório 0700 e link interno restaurados com a capacidade CHOWN.

[V] A idade do frame recebido foi 2,008 s; isso é frescor no instante da conexão, **não medição de latência simulador→tela**. NF01 e os demais ensaios de carga, recuperação e LLM continuam separados.
